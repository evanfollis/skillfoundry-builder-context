# Builder Context

This repository is the durable context lineage for Skillfoundry’s builder.
Treat `memory/` and promoted `bundles/` as authoritative Git-governed records.
Keep raw or mutable run state out of canon. Preserve the role-specific mission,
profile, findings, plans, decisions, and contracts. Run `make check` before
committing. Promotion remains explicit and evidence-gated through
`skillfoundry-harness`; automation does not imply approval.

Read `docs/architecture.md` for artifact roles and migration exceptions.
